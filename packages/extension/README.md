# Chrome Media Recorder Extension

Chrome 扩展，通过 `chrome.debugger` 拦截当前标签页的网络媒体响应，并支持右键图片或扫描当前页面的一次性捕获，保存到本地 VFS 服务。界面分为两个明确的表面：

- **Side Panel（捕获驾驶舱）**：只监控当前标签页上的单次捕获会话，显示实时媒体流、会话指标和可展开的事件日志。
- **Options（控制台）**：全局媒体库、标签治理、AI 任务和程序配置。

## 功能

- **一次性捕获**：右键图片保存，或在 Side Panel 右上角点击「抓取本页媒体」图标扫描当前页面；支持 `http(s)`、`data:`、`blob:` 图片，预览后可多选批量保存，不创建捕获会话、不触发 debugger 提示。
- **单捕获会话**：全局同时只允许一个标签页进行持续捕获；切换捕获标签页需要显式确认。
- **标签页绑定**：Side Panel 始终显示当前标签页身份；会话在另一个标签页运行时显示切换/停止横幅。
- **实时诊断**：保存、重复、跳过、失败、视频候选/结果和 AI 状态都会进入会话事件日志。
- **全局媒体库**：在 Options 中浏览、搜索、排序、多选、查看详情、删除、重新入队和导出。
- **统一搜索框**：一个输入框支持自由词 AND、`tag:` / `site:` / `type:` / `status:` / `date:` / `starred` 维度、`tag:a|b` OR 和 `-排除`，并提供标签、站点、最近搜索与快捷筛选建议。
- **可读导出**：单文件下载使用 AI 文件名；多选导出生成 zip 和 `metadata.json`。
- **元数据整理**：在详情中收藏、下载和前后导航；标签以 `#tag` 只读展示，不提供备注或标签编辑。
- **智能去重**：基于 SHA-256 内容哈希。
- **媒体格式**：图片（JPEG、PNG、WebP、GIF、BMP）和视频（MP4、WebM、MOV、AVI）。
- **深色/浅色主题**与多语言支持。

## 页面职责

| 页面             | 职责                                                                                       | 不做的事                              |
| ---------------- | ------------------------------------------------------------------------------------------ | ------------------------------------- |
| Side Panel       | 当前标签页身份、捕获开关、抓取本页/一次性保存、会话指标、实时捕获流、事件日志、会话总结    | 全局历史瀑布流、标签治理、AI/任务配置 |
| Options > 概览   | 服务状态、存储与媒体统计、AI 队列快照、最近捕获、只读会话状态                              | 启动/停止捕获                         |
| Options > 媒体库 | 全局历史媒体、统一搜索与筛选、回收站视图、详情、删除、重新分类/命名                        | 捕获控制                              |
| Options > 标签   | AI 标签词表、置顶、重命名、合并、删除                                                      | —                                     |
| Options > 任务   | AI 队列控制台、并发、重试/清空/重扫                                                        | —                                     |
| Options > 设置   | 常用设置（视频捕获、Ollama、主题）与折叠的「高级与诊断」（服务、索引、工作区、视频高级项） | —                                     |

## 使用

1. 启动本地 app（`pnpm dev` 或 `pnpm --filter app start`）。
2. 在任意普通网页点击扩展图标，打开 Chrome 右侧 Side Panel。
3. 点击「开始捕获」开始当前标签页的会话。
4. 会话中可查看实时捕获流；展开「事件日志」查看跳过/失败原因。
5. 切换到其他标签页时，Side Panel 会显示「另一个标签页正在捕获」横幅。
6. 在 Side Panel 中打开媒体库或设置，会跳转到对应的 Options 控制台标签。

全局只允许一个捕获会话。在另一个标签页开始捕获时，扩展会先要求确认，确认后停止旧会话并启动新会话。

捕获启用时，Chrome 可能显示当前标签页正在被调试的提示；停止会话会释放该标签页的 debugger 会话。

持续捕获会话聚焦网络媒体响应：不还原 Canvas/WebGL 生成的 `data:` 图片或页面内组装的 `blob:` 图片，也不承诺还原复杂视频流、Range 分片或 MSE 播放内容。一次性捕获会尝试保存页面中已经存在的 `data:` / `blob:` 图片（受页面 CSP、blob 生命周期和跨域限制），但不扫描 canvas 像素本身。这些情况会尽量以跳过/失败结果或会话诊断事件显示。

## 结构

```
extension/
├── src/
│   ├── entrypoints/
│   │   ├── background/        # Service Worker、会话存储、消息转发
│   │   ├── sidepanel/         # 捕获驾驶舱
│   │   ├── options/           # 控制台与全局媒体库
│   │   ├── media-browser/     # 共享媒体网格、详情与事件 hooks
│   │   └── offscreen/         # 视频下载执行上下文
│   ├── background/            # CDP 捕获、视频下载、VFS 中继、会话存储
│   └── shared/                # 共享运行时消息与类型
└── wxt.config.ts              # WXT 配置
```
